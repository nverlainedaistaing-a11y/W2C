My Command Line Learning Journey

Exploring the power of the Command Line Interface

What I Have Learned

So far, I have learned the following:

  1. How to navigate through directories using commands like cd, ls, and pwd.
  2. How to create, delete, and manage files and directories using commands like touch, mkdir, rm, and rmdir.
  3. How to view the contents of files using commands like cat, less, and head.
  4. How to use command line text editors like Git Bash locally or in VS Code.
  5. How to use pipes and redirection to manipulate command output.
  6. Understanding file permissions and how to change them using chmod.
  7. How to create a GitHub repository and push local changes to it using Git commands.

Overall, I have gained a solid understanding of the command line interface and its capabilities. I feel more confident in navigating and managing files and directories, as well as utilizing various commands to perform tasks efficiently.
